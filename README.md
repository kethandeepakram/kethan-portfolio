# R. Kethan Deepak Ram — Portfolio

Professional React + Vite portfolio for a fresher Java Full Stack Developer.

## Features
- Recruiter-focused one-page portfolio
- Hero section with profile photo
- About / career objective
- Technical skills
- Projects sourced from the supplied resume
- Education
- Certifications
- Research achievements
- Contact section
- Resume view/download
- Dark/light theme
- Smooth section navigation
- Responsive mobile layout

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
Push the project to GitHub, then import the repository into Vercel or Netlify.
